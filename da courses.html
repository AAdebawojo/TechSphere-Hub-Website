About the programme

Skills you can put to work.

The Data Analysis Bootcamp is designed to equip you with the essential skills to turn raw data into valuable insights that drive smarter decision-making. Whether you are transitioning from another career or starting fresh, this program will guide you to become a Data Analyst or Business Intelligence Analyst, capable of working across industries like Healthcare, Finance, E-commerce, and Telecommunications.

In just 16 weekends, you’ll master in-demand tools such as Excel, SQL, Tableau and Power BI for data analytics, while building a diverse portfolio of projects from real-world business scenarios. This program is modeled on global industry standards, preparing you to earn dual certifications — a Certificate of Completion from TechSphere Hub Academy and a recommended Microsoft Power BI Data Analyst Certification (optional, external exam).

Your learning journey

What you’ll learn.

01Excel for Data Analysis

This course provides a practical introduction to Microsoft Excel for data analysis across fields like business, marketing, and research. Designed for beginners, it equips learners with essential Excel skills for analysing data, making it ideal for aspiring Data Analysts, Data Scientists, or anyone seeking to apply Excel in their domain with no prior experience required.

02SQL for Data Retrieval

This course offers a hands-on introduction to using relational databases like MySQL and Microsoft SQL Server for data and business analysis. Learners will gain a solid understanding of how relational databases work, how to design entity-relationship diagrams, and how to retrieve and aggregate data through SQL queries. Designed for beginners with no prior coding experience, this course empowers students to access and analyse business data independently, build a portfolio of practical SQL queries, and gain a competitive edge in today's data-driven business environment. MySQL and SQL Server are among the most widely used database technologies globally, making these skills highly valuable across industries.

03Power BI

This course equips you with the skills to use Microsoft Power BI for creating dynamic, interactive dashboards and business intelligence reports. You'll learn how to connect multiple data sources, apply AI-driven insights, and develop visually immersive reports to support data-driven decision-making. Through hands-on training, you’ll master best practices for preparing, modeling, visualizing, analyzing, and managing data assets in Power BI, enabling you to uncover actionable insights and drive business results with confidence.

04Tableau

This course trains you to become proficient in Tableau for deriving insights from large, complex datasets and presenting them through impactful, interactive visualizations. You'll learn essential data literacy skills, build your first Tableau workbooks, connect and clean data, and create dynamic dashboards and stories. The training covers advanced techniques including calculations, LOD expressions, table calculations, and user controls like parameters. You'll also gain experience managing content through Tableau Server and Tableau Cloud, understanding governance, and publishing best-practice dashboards to inform business decisions. Designed for aspiring analysts, this course empowers you to independently explore data, create reports, and uncover valuable business opportunities.

05Problem-Solving Techniques

Root cause analysis is a critical skill that distinguishes effective problem-solving from merely addressing symptoms. Mastering this approach involves identifying the problem, uncovering contributing factors, and diagnosing the true root cause. With the right knowledge and analytical skills, individuals can thoroughly resolve challenges and implement lasting solutions.

About the programme

Skills you can put to work.

The QA Testing Bootcamp is your gateway to launching a career ensuring the quality and reliability of software systems. Whether you have a technical background or none at all, this program trains you in manual testing fundamentals, defect tracking, basic automation, and API testing essentials.

Over 6 weekends, you’ll learn how to design test plans, execute test cases, file detailed bug reports, and explore automation testing using Selenium and API validation using Postman. Tools like JIRA and TestRail will become part of your everyday professional toolkit.

Your learning journey

What you’ll learn.

01Manual Testing

Gain a strong foundation in software quality assurance by learning how to design effective test cases, execute detailed quality checks, and ensure products meet business and technical requirements.

02Bug Reporting

Master best practices in tracking, documenting, and reporting bugs using industry-standard tools like JIRA and TestRail, enhancing communication between QA and development teams.

03Automation Basics

Take your QA skills further with an introduction to automation scripting using Selenium. Learn how to automate repetitive tests and improve software testing efficiency.

04API Testing

Learn how to validate and verify API endpoints using Postman, ensuring seamless integration between software components and maintaining system reliability.
